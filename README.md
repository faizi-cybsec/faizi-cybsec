A zero-dependency **Python SOC log analyzer** with a Sigma-style detection rule engine, offline IOC enrichment, and MITRE ATT&CK-mapped incident triage. Reads Linux, web, and cloud logs and produces prioritized incident reports (terminal, JSON, CSV, HTML). Released as **v1.0.0** with automated tests and CI.
